# 地圖英數字形

GIS 地圖標籤的英文、數字用的 MapLibre 字形檔（PBF），只放 `0-255` 一個範圍。中文由瀏覽器以本機字型繪製（`localIdeographFontFamily`），不需要字形檔。

| 檔案 | 來源 |
|---|---|
| `Klokantech Noto Sans Regular/0-255.pbf` | GitHub `openmaptiles/fonts`，`gh-pages` 分支 commit `025ff2b2f84cc0fdf11f7b1d74b3a784595fe7a4`（2026-10-17 下載） |

授權：Noto Sans，SIL Open Font License 1.1（OFL），授權全文與著作權聲明在 `OFL.txt`（取自 `notofonts/latin-greek-cyrillic`），隨字形一起部署。

放在本站，網站執行時不連任何第三方字型服務。
